# 使用说明

## 第一次打开

安装版打开 `Shiori-Setup`，按向导选择安装位置，完成后可从开始菜单或桌面打开。便携版解压到可写的文件夹，打开 `Shiori.exe`。

在首次设置里选择游戏目录，可一次选择多个文件夹。原有游戏文件和会社、作者、系列文件夹均可继续使用。

如果已经有 Bangumi 账号，可以在此时连接；也可以进入偏好设置后再连接。完成目录选择后，点击「进入我的收藏」。

## 添加与扫描游戏

收藏馆右上角可添加新的游戏目录或立即扫描。目录变化稳定约 7 秒后会自动扫描，也会每 60 秒复查。关闭启动器期间加入的游戏会在下次打开时发现。

遇到未收录的作品，点击「添加 EXE」，直接选择游戏启动文件。进入游戏详情的编辑页，可以更换启动程序和设置启动参数。有多个启动程序时，优先选择自己平常使用的汉化或正式启动文件。

偏好设置中可以停止扫描某个目录，已经收录的作品和记录仍保留。

## 连接 Bangumi

在偏好设置中找到 Bangumi，点击「登录 / 创建 Token」，在官方页面注册或登录并创建个人访问令牌。返回 Shiori 粘贴令牌，点击连接。

部分游戏条目需要登录权限。令牌加密保存在当前 Windows 用户的本地环境中，换电脑后重新连接。点击断开连接会删除 Shiori 保存的凭据。

VNDB 公共资料可直接查询。2DFan 的评分与讨论在浏览器中打开，并使用网站自己的登录状态。

## 匹配封面和资料

打开游戏详情，选择「匹配游戏资料」。可以输入中文、日文或英文名称，选择 Bangumi 或 VNDB 搜索，检查作品名称、平台及发行时间后关联。

也可以粘贴明确的作品链接：

```text
https://bgm.tv/subject/123
https://vndb.org/v123
```

简写 `bgm:123` 和 `v123` 也可使用。Bangumi 关联会验证条目类型；同名动画不能作为游戏资料保存。

手动关联会成为后续使用的资料。编辑页还可以补充其他社区链接、自定义封面与显示名称。

## 整理标签与侧栏

打开「标签一览」，切换会社、系列、脚本家、作品标签、原目录或自定义分类。搜索支持已有别名，展开标签可查看相关作品与资料来源。

勾选想常用的标签，点击「保存侧栏标签」。只有保存的标签会显示到侧栏，完整分类仍可在标签一览中查找。脚本家也可以整体隐藏，或按作品设置是否显示。

点击标签会按该分类查找作品；点击另一个标签会替换当前筛选。自定义标签、会社、作者和系列可在游戏的编辑页补充。

## 启动与兼容设置

点击封面上的播放按钮，或进入详情点击启动。游戏会使用自身所在目录作为工作目录。

需要日语环境的 Windows 游戏：先安装 Locale Emulator，在偏好设置中选择 `LEProc.exe`，再为对应游戏启用「LE 转区启动」。使用与 LE 兼容的 32 位游戏程序。

主机游戏镜像：在游戏编辑页选择已安装的模拟器，并设置启动参数。参数中的 `{game}` 会替换为镜像路径。

需要光盘环境的部分老游戏：Shiori 会依据已有的兼容配置，在启动时准备临时光驱，游戏结束后释放由 Shiori 创建的设备。其他引擎依照游戏本身的运行库和安装要求配置。

没有出现游戏窗口时，查看详情中的启动提示，并确认启动文件、运行库、转区和模拟器设置。

## 时长与通关状态

游戏窗口运行后开始记录时长，休眠期间暂停计入。可以在详情中暂停或结束计时；结束计时只保存当前记录，游戏仍继续运行。

在状态下拉框中自行选择「已通关」。收藏馆的「批量标记通关」可以一次处理多部作品。以前玩过的时长可在编辑页补录。

关闭启动器窗口时，正在进行的计时会保留在托盘中；游戏结束后保存记录。

## 备份与迁移

便携版的 `data/` 保存设置、游戏库、缓存和记录。退出 Shiori 后，可备份整个便携目录。搬到另一台电脑后，检查游戏路径，重新连接 Bangumi，并按需设置 LE 和模拟器。

安装版将资料保存在当前 Windows 用户的 `AppData/Shiori`。卸载程序时保留这些资料，再次安装后可以继续使用；偏好设置中的「打开数据目录」可直接找到它。

偏好设置还提供资料与记录导出。游戏库写入时保留上次备份及最近 14 天的每日快照。

开发运行默认使用 `.local-data/`。非便携打包运行使用当前用户的 `AppData/Shiori`；需要独立测试库时可设置 `SHIORI_DATA_DIR`。
