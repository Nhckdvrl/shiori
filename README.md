# 栞 Shiori

让每个故事，都有栖身之处。

Shiori 是一个 Windows Galgame 启动器。把游戏目录交给它，整理封面与资料，按会社、系列和脚本家找到作品，再从上次停下的地方继续。

浅色界面，淡紫点缀。标题使用得意黑，日常操作使用 MiSans。

## 开始收藏

从仓库的 **Releases** 下载 Windows x64 便携版，解压后打开 `Shiori.exe`。

1. 选择游戏文件夹。支持多个目录、不同磁盘，以及现有的会社、作者和系列目录结构。
2. 按需连接 Bangumi。登录官方页面，创建个人访问令牌，然后粘贴到首次设置中。
3. 进入收藏馆。游戏会自动收录，资料匹配在后台进行；新增游戏后也会自动扫描。

日常操作与常见设置见 [使用说明](docs/使用说明.md)。

## 找到想读的故事

- **封面收藏馆**：搜索作品、会社、系列或脚本家，切换封面墙与列表，收藏想重温的作品。
- **自动收录**：递归查找启动文件，识别常见汉化启动程序，保留原目录分类；也可直接添加 EXE。
- **清楚的标签**：会社、系列、脚本家、作品标签和自定义分类分别管理。勾选并保存后，标签才会出现在侧栏。点击新标签会替换当前筛选。
- **资料与社区**：自动匹配封面、介绍、制作人员和评分。详情页可前往 Bangumi、VNDB、2DFan 阅读讨论、查看攻略或参与评分。
- **自己的进度**：按实际游戏进程记录时长，支持暂停计时和补录历史时长。「已通关」由自己标记，也支持批量操作。
- **灵活启动**：支持选择启动程序、独立参数、Locale Emulator 转区和模拟器；部分老游戏可使用临时光驱兼容。

## 资料从哪里来

| 来源 | 主要用途 |
| --- | --- |
| Bangumi | 游戏条目、封面、介绍、会社、制作人员与评分 |
| VNDB | 多语言标题、游戏信息、剧本署名与评分 |
| 2DFan | 公开作品资料、攻略及讨论入口 |

会社以 Bangumi 的开发、品牌及关联会社身份为主，发行商单独记录。作者别名和姓名写法会归并，系列包含本篇、续作与外传。

匹配同时参考标题、别名、系列编号、会社和平台。需要确认的作品会保留候选项；详情页的「匹配游戏资料」支持搜索数据库或直接粘贴作品链接。评分旁始终显示对应资料源。

## 数据与隐私

便携版将设置、游戏库、手记和计时保存到程序旁的 `data/`。在线查询会向资料平台发送检索的游戏名称。Bangumi 令牌使用 Windows 加密保存在独立文件中，仅发送给 Bangumi API；换电脑后重新连接即可。

可在偏好设置中导出资料与游玩记录。导出文件包含游戏路径与手记，适合自行备份。提问或提交问题时，请使用示例路径，并隐藏账号、令牌和私人记录。

## 开发

运行环境：Windows 10/11 x64、Node.js 24、pnpm 11。

```powershell
pnpm install --frozen-lockfile
pnpm start
```

```powershell
pnpm test
pnpm test:e2e
pnpm package
pnpm test:tags
pnpm test:portability
pnpm check:release
```

便携版输出到 `dist/`。自动测试使用独立示例目录，覆盖扫描、资料匹配、标签管理、Windows 窗口启动、计时、数据保存和迁移后的首次使用。

欢迎通过 Issues 提交问题和建议，通过 Pull Requests 参与开发。报告启动问题时，请附上系统版本、启动方式、错误提示与去除个人信息的复现步骤。
